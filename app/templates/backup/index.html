Restaurar Backup del Sistema
¡Importante! Esta operación reemplazará los datos actuales. Se recomienda hacer un backup antes de restaurar.
Restaurar Backup Completo (.zip)

Restaura todo el sistema ERP incluyendo base de datos, documentos, archivos y configuraciones. Recomendado para recuperación completa.

  • 📦 Archivo comprimido con todo el sistema
  • 🔄 Restaura base de datos, documentos y archivos
  • ⚙️ Incluye configuraciones del sistema
  • 🛡️ Mayor tamaño pero recuperación total
Restaurar Solo Base de Datos (.db)

Restaura únicamente la base de datos SQLite con clientes, préstamos, pagos y socios. Mantiene documentos y archivos actuales.

  • 🗄️ Solo base de datos SQLite
  • 📁 Mantiene documentos y archivos actuales
  • ⚡ Restauración más rápida
  • 🔄 Compatible con backups antiguos
Archivos soportados: .zip (backup completo) o .db (solo base de datos) - Máximo: 30GB para ambos tipos
